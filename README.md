# Venue Booking System
A simple venue booking system developed using Assembly Language as part of my Diploma in Information Technology coursework. 
Download the file to the DOSbox 8086 file and mount c: disk in the DOSbox and open the main code file in Notepad++ to run

## Features
* Venue booking
* Booking information management
* Venue selection
* Booking details management

## Technology
* Assembly Language

## Project Type
Academic Project
